# Software-Security

# Briefly summarize your client, Artemis Financial, and its software requirements. Who was the client? What issue did the company want you to address?
The client I had was Artemis Financial which is a financial consulting company that develops personalized financial plans and manages sensitive client data. Because of the nature of their services, Artemis required that their web based financial application was secure and compliant with the best practices in software security. The goal for their project was to strengthen their codebase, implement encryption for data in transit, and make sure that their software development practices aligned with industry security standards.

# What did you do well when you found your client’s software security vulnerabilities? Why is it important to code securely? What value does software security add to a company’s overall well-being?
For this project, I think I did well with reducing the vulnerabilities and applying secure coding practices. It's important to code securely because the vulnerabilities can lead to data exposure, financial loss and reputational damage. A strong software security increases the user's trust, prevents any unauthorized access, and makes sure the long term stability of the organization’s operations.

# Which part of the vulnerability assessment was challenging or helpful to you?
The most difficult thing for this project was getting the website to work with me. It kept telling me it refused to connect. But with the help of my professor I was able to figure it out and solve the issue. 

# How did you increase layers of security? In the future, what would you use to assess vulnerabilities and decide which mitigation techniques to use?
I increased the layers of security by using SSL/TLS encryption, removing any dependencies that are unnecessary, applying input validation, and following the secure exception handling practices. For the future I shall keep using OWASP tools like Dependency-Check and the others to help me identify any vulnerabilities early and quickly. I would also apply the risk-based prioritization to help determine the most effective mitigation techniques.

# How did you make certain the code and software application were functional and secure? After refactoring the code, how did you check to see whether you introduced new vulnerabilities?
I verified that the application stayed functional by running it locally and confirming that all of the endpoints operated correctly under HTTPS. I did do a re-run with a vulnerability scan after refactoring to make sue that the previously detected issues were mitigate and that there was no new vulnerabilities. 

# What resources, tools, or coding practices did you use that might be helpful in future assignments or tasks?
The resources, tools and coding practices I used and most likely will use again are OWASP Dependency-Check for vulnerability scanning, secure coding principles for an example least privilege, input sanitization, and proper exception handling, Java Spring Boot security configurations, and SSL/TLS certificate generation for the encrypted communication.
